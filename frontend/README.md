# Lunar Image Registration Dashboard (Frontend)

This directory is reserved for the frontend interactive web dashboard for the SIH26166 lunar image registration system.

## Planned Capabilities
- **Multi-Sensor Ingestion Portal**: Drag-and-drop ingestion of Chandrayaan-2 (OHRC, TMC-2, IIRS) and LROC ZIP archives.
- **Footprint & Orbital Swath Visualizer**: Interactive 2D/3D lunar sphere with PostGIS footprint swaths and common-area intersection display.
- **Quality Assurance Dashboard**: Interactive charts showing NoData %, pixel saturation, dynamic range histograms, and metadata flags.
- **Correspondence & Registration Viewer**: Split-screen swipe / checkerboard viewer comparing unregistered vs registered orbital rasters with keypoint correspondence vector overlays.
- **Accuracy Benchmarking**: Metric summary tables (RMSE, SSIM, PSNR) and exportable scientific PDF/CSV reports.
